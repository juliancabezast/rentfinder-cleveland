# Two fixes, 2026-08-08:
#  1. Googlebot and Bingbot used to have a group containing only "Allow: /".
#     Per RFC 9309 a crawler obeys ONLY the group matching its own name and
#     never merges it with "*", so those two groups silently voided all 25
#     Disallow rules for the exact crawlers they were meant to guide — the
#     private panel was open to both. Every named group now carries the full
#     list, so an agent-specific group can never widen access again.
#  2. The blanket "Allow: /" is gone. Google resolves conflicts by longest
#     match (Disallow wins), but first-match parsers read "Allow: /" first and
#     drop every Disallow after it. Allow-by-default is the standard, so the
#     line bought nothing and made the file mean two different things depending
#     on who read it.
